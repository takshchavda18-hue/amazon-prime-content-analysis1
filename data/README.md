# Data

Place the raw dataset here as `amazon_prime_titles.csv`.

1. Open https://www.kaggle.com/datasets/shivamb/amazon-prime-movies-and-tv-shows
2. Click Download and unzip the archive.
3. Copy `amazon_prime_titles.csv` into this folder.

Expected columns: show_id, type, title, director, cast, country, date_added,
release_year, rating, duration, listed_in, description.

Running the notebook also creates `amazon_prime_cleaned.csv` in this folder.
